# RASP5 end-to-end tutorials

These tutorials use fixed datasets distributed with the RASP5 application
package. Paths are relative to the RASP5 installation or source directory.

- [Psychotria ancestral-range reconstruction](Psychotria_end_to_end.md)
- [BayArea DISTANCE NORM multi-chain convergence](BayArea_distance_norm_convergence.md)
- [Primate trait reconstruction](Primate_trait_end_to_end.md)
- [Dore Ponerinae spatial and BSM workflow](Dore_spatial_bsm_end_to_end.md)

The tutorials distinguish a short workflow check from a scientific production
run. A preview or reduced stochastic-map count is not a substitute for the
documented production settings.

Every new engine run writes `rasp5_provenance.json` beside its native outputs.
Keep this file with exported tables and figures.

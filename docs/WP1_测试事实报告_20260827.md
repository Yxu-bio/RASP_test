## 4. Phase 2 独立契约

`tools/run_phase2_spatial_checks.py` 不再调用 Phase 1。它独立构造 BioGeoBEARS raw tables，并验证：

1. anagenetic/cladogenetic raw row 到 normalized event schema；
2. event type、time bin、CSV 行数和导出字段；
3. Spatial Project JSON 保存/载入后区域元数据保持；
4. anagenetic 与 founder event 聚合、`mean_per_map` 分母；
5. edge/node CSV 与 GeoJSON 导出；
6. 将预计算 edge/node 表写入磁盘后，经 `BioGeoBEARSAnalysisService.load_existing_bsm_events()` 真实载入；
7. Map/Circle 只改变布局，不改变统计 edge table；
8. 手工曲率在 edge width、labels、threshold 刷新及 layout JSON round-trip 后保持。

固定结果：6 normalized events、5 network edges；阈值 `mean_per_map >= 0.5` 后 3 条 display edges。

## 5. Dore 衍生的 RASP adjacency-path 1000-map 规范

规范文件：`data/benchmarks/dore_ponerinae/dore_bsm_1000_benchmark_spec.json`
执行工具：`tools/run_dore_bsm_benchmark.py`

作者来源固定为仓库 commit `ea39cdd63c101eeadc92a39d7aa23e19aab27b56`：

- `scripts/04_Fit_biogeographic_models.R`, SHA256 `84E7FBEF66FA4D52C46FD318CC81BF0E195FDD8338A6E83A5F0A9D6D55583FE8`；
- `scripts/05_Biogeographic_Stochastic_Mapping.R`, SHA256 `341AC5E6AD92523A17769297DC20B532E3DA0B57952D875C957A0F337A924326`。

固定分析参数：DEC+J、`max_range_size=5`、include null range、1 core、7 个 period、`jstart=0.0001`、1000 maps、seed 12345、`maxnum_maps_to_try=200`、`maxtries_per_branch=40000`。

作者模型脚本把按 adjacency 推导的允许状态列表直接写入 `lists_of_states_lists_0based`，而当前 RASP 路径把同一批矩阵写入 `areas_adjacency_fn`。两条路径尚未逐期证明产生完全相同的 state lists。因此，该资产是 **Dore 衍生的 RASP adjacency-path 基准**，不是论文等价数值复现。这个边界由规范文件和每次运行 manifest 同时记录。

验证结果：

- 1534 tree tips 与 1534 matrix rows 完全匹配；
- 显示区域名显式编码为 `A/U/I/R/N/E/W`；
- 按作者源码显式应用 `NewGenus_bucki_EX2455_DZUP549431 -> Neoponera_bucki`；
- 7 个 adjacency matrices 与 7 个 period boundaries 完整读取；
- observed maximum tip range size 为 3；
- runtime include list 共 120 个状态，最长状态严格为 5 区，与 `max_range_size=5` 一致；
- BioGeoBEARS tree/geog/areas/time-period/adjacency 文件可确定性生成。

仅验证输入和运行文件：

```powershell
E:\Anaconda3\envs\RASP\python.exe tools\run_dore_bsm_benchmark.py --validate-only
```

执行正式 1000-map 重建时移除 `--validate-only`。每次验证或运行都写入独立的 `validate_<timestamp>_<fingerprint>` / `run_<timestamp>_<fingerprint>` 子目录，避免验证、正式长跑或不同参数互相覆盖。当前验证 manifest 为：

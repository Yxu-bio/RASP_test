## 2. Dore 1000-map 正式实算

固定案例使用 1534-tip Ponerinae 时间树、7 个区域、DEC+J、7 个时间段、
`max_range_size=5`、`include_null_range=true`、`seed=12345` 和 1000 张 BSM。
每个时间段采用 Dore 作者脚本的手工 allowed-state 规则，状态数依次为：

```text
36, 36, 27, 20, 24, 20, 38
```

BSM 完成 1000/1000 maps，随机映射阶段耗时 9109.325 秒。原始结果包含：

- 152,498 行 anagenetic event table；
- 4,074,000 行 cladogenetic event table；
- 1,685,498 个可归类事件；
- 152,775 个按标准解析器六位小数精度区分的事件时间点。

正式运行证据位于：

`runs/benchmarks/dore_bsm_1000/run_20260828_133706_013698_27b0be378a68/benchmark_manifest.json`

运行最初在 BSM 完成后被旧 CSV exporter 以非零状态结束。最终 RData 和完整
CSV 均已写成，因此没有重跑 1000 maps；恢复过程和原始错误均保留在 manifest
的 `recovery` 字段中。完整服务路径扫描约 1.08 GB CSV 用时 199.372 秒。

## 3. 网络统计语义

Dore/BioGeoBEARS 的正式口径不是把多区域祖先范围平均分给所有可能来源区。
RASP5 现在对新生成的 BSM 调用：

1. `BioGeoBEARS::simulate_source_areas_ana_clado()`，为每个扩散事件抽取唯一来源区；
2. `BioGeoBEARS::count_ana_clado_events()`，生成官方 from-to 计数；
3. Python 只读取唯一来源事件并构建表格、地图和网络图。

新结果记录 `biogeobears_probabilistic_unique_source`。旧的外部结果若没有来源区
字段，仍可显式使用 `fractional_equal_split_fallback`，但不会伪装成官方口径。

正式 1000-map 对照覆盖 42 条有向边以及 `anagenetic_count`、`founder_count`、
`total_count`、`mean_per_map` 四个字段：

```text
reference edges: 42
RASP edges:      42
mismatches:       0
max abs diff:     0.0
```

关键边也复现了论文图中的整数标签，例如 `I->U=88.905`、`I->E=49.978`、
`U->I=41.444`、`A->I=36.865`、`N->R=16.319`。

## 1. 本阶段回答的问题

本阶段不判断生物学结果是否收敛，而是验证用户可编辑参数是否真正穿过 RASP 数据流并改变原生引擎输出：

```text
GUI/config model
  -> analysis service / dataset builder
  -> raw engine config and input
  -> native executable
  -> raw stdout / JSON / MCMC files
  -> parsed result
```

自动入口：

```powershell
E:\Anaconda3\envs\RASP\python.exe tools\run_wp2_parameter_contract_checks.py
```

固定输入位于 `data/benchmarks/psychotria/`，期望值与输入/engine SHA-256 位于 `wp2_parameter_contract_expected.json`。每次运行使用独立 `runs/wp2_parameter_contract/<timestamp>/`，保留 raw config、stdout、JSON 和 BayArea 原始链文件。

## 2. 参数路径

| 方法 | GUI/config | 写入与执行 | 原始证据 | 解析结果 |
| --- | --- | --- | --- | --- |
| DEC | `DECConfigDialog` / `SDECConfig` | `DECAnalysisService -> DECDatasetBuilder -> DECRunner` | `run.conf`、period matrix、lagrange stdout、`*.results.json` | DEC result/parser |
| S-DEC | `SDECConfigDialog` / `SDECConfig` | `SDECAnalysisService` 逐树调度同一 DEC 链 | 每树 `run.conf` 和原生结果 | S-DEC clade merge |
| BayArea | `BayAreaConfigDialog` / `BayAreaConfig` | `BayAreaAnalysisService -> BayArea runner` | manifest、stdout、parameters、area_states | `BioGeoBEARSResult` 兼容结果 schema |

主窗口入口分别位于 `gui/main_window.py` 的 `run_dec`、`run_sdec` 和 `run_bayarea`。本阶段测试直接从相同 config model/service 入口调用，避免只验证手工拼接命令。

## 3. lagrange-ng 原生契约

### 3.1 固定 d/e 与 maxareas

Psychotria 固定 `dispersion=2.0`、`extinction=3.0`、`maxareas=2`。检查同时覆盖：

- `run.conf` 实际写值；
- stdout 实际报告值；
- 原生 JSON `params`、`max-areas`、`state-count`；
- LLH `-111.4978 +/- 0.0002`。

因此这不是“界面有参数”检查，而是原生 engine output 检查。

### 3.2 时间分层 d/e、matrix 与 exclude

三段 period 的 d/e 为：

| Period | dispersion | extinction | 来源 |
| --- | ---: | ---: | --- |
| 0 | 0.5 | 0.8 | period override |
| 1 | 0.001 | 0.002 | period override |
| 2 | 2.0 | 3.0 | global fallback |

四路控制实验结果：

| Variant | Matrix | Exclude | LLH |
| --- | --- | --- | ---: |
| baseline | no | no | -86.5078 |
| matrix only | A-B = 0.5 | no | -86.50876 |
| exclude only | no | period 2 `0001` | -100.1430 |
| combined | A-B = 0.5 | period 2 `0001` | -100.1437 |

matrix 路径还要求原生 JSON 的 period 1 `distance-penalty=1.0`；baseline 必须为 null。四个 likelihood 均不同，证明 matrix 与 exclude 不是只写入文本的空壳。

### 3.3 本阶段发现并修复的问题

`DECDatasetBuilder` 原先只有 matrix 非默认或存在 area rule 时才输出 period 定义。因此用户只配置时间边界和 period d/e、同时 matrix 全为 1 时，rate 行会引用不存在的 period，lagrange-ng 直接拒绝配置。

修复后，只要存在两个以上时间边界，builder 就输出 period 定义。默认单 period 行为不变。Phase 0 全链回归已通过。

## 4. BayArea 原生契约

这些测试使用一轮采样作为接线诊断，不能解释为收敛的 MCMC 生物学结果。

覆盖内容：

- 相同 seed 下 prior scale 从 0.1 改到 1.0，gain/loss/distance-power 初值精确变为 10 倍；
- `Guess Initial Rates=False/True` 产生不同、固定的原生初值；
- stdout 与 manifest 均记录实际 seed、prior 和 initial-rate mode；
- 两条独立链使用 seed `13579` 与 `1013582`，不同 seed 产生不同原生文件；
- 相同 base seed 的完整双链重复运行，原始 parameters/states/probs/NHX 文件逐字节一致；
- 合并结果的每个节点状态计数等于两条链 raw `area_states` 的计数和；
- 用户可见 state support 等于 `combined count / combined sample count * 100`。

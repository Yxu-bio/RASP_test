# Installer translations

`ChineseSimplified.isl` is the unofficial Simplified Chinese translation
carried in the official Inno Setup source repository.

- Upstream tag: `is-6_7_3`
- Source: `Files/Languages/Unofficial/ChineseSimplified.isl`
- SHA256: `7D544B9BB1D142CFA11F2E5D3CC8ABE2E55F8E066C5124E3772675AA236E1278`
- Upstream URL: <https://github.com/jrsoftware/issrc/tree/is-6_7_3>

Keeping the translation beside `RASP5.iss` makes installer builds independent
of optional language files in a developer's local Inno Setup installation.
